                                            o c p x 媒体接口文档 1.4

具体文档

1. 概览

在广告发生曝光/点击等监测事件时，由媒体或三方 DSP 调用我方分配的监测回传链接，链接须宏替换，完成我方对投放行为数据收集，

我方对后续转化事件进行归因匹配后，调用媒体预留链接，将相关转化信息回传给媒体或三方 DSP。




2. 我方监测地址获取

在媒体或三方 DSP 完成文档接入后由我方运营人员提供。




3. 曝光/点击接口（媒体或三方 DSP 发生曝光/点击时调用）

      4. 用户行为回传

我方完成行为归因后，将点击接收接口下发的 callback 拼接上&actionType={actionType}&amount={amount}，然后以 HTTP GET 方式回
传，其中站位符{actionType}是行为类型，{amount}是在发生支付相关行为时的金额（单位：分）

例如：

点击上报的 callback 为 http://test.demo.com/track/activate?sid=1234，
                                                             我方在用户发生行为时会在 callback 后拼接 actionType 参数拼装后
的完整回调链接为 http://test.demo.com/track/activate?sid=1234&actionType={actionType}



激活事件回调示例：http://test.demo.com/track/activate?sid=1234&actionType=1
