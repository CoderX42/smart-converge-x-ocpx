                                 中森跃动 ocpx 媒体接口文档 1.4

具体文档


1. 概览

媒体或三方 DSP 在广告曝光、点击时调用 SCX 下发的监测地址并替换地址中的宏，SCX 收集投放行为并向已配置的广告主转发。

广告主回传转化后，SCX 完成归因、去重与扣量判定，再调用原请求中的 callback_url，将转化结果回传媒体或三方 DSP。



2. SCX 监测地址获取

媒体完成文档接入后，由中森跃动运营人员在 SCX 管理端创建监测任务并提供曝光、点击两条完整地址。媒体只替换宏，不得修改四个

路由参数及 event 固定值。

 https://{SCX_HOST}/ocpx/feedback?request_id=__REQUEST_ID__&callback_url=__CALLBACK_URL__&event=IMP&mId={mediaId}&tId={taskId}
 &aId={advertiserId}&lId={linkId}


3. 曝光/点击接口（媒体或三方 DSP 发生曝光/点击时调用）

 接口类型：http/https（实际联调与生产均以运营下发的完整地址为准）
 请求类型：GET
 接口路径：/ocpx/feedback；event=IMP 表示曝光，event=CLK 表示点击

 响应：

HTTP 状态码 200 表示 SCX 的 Feedback 事实事务已成功提交；不等同于广告主已接受转化。

 {
  "ret": 0,
  "code": 200,

     "msg": "提交成功",
  "data": {}
 }


4. 用户行为回传

SCX 完成行为归因、去重和扣量判定后，读取曝光/点击请求中的 callback_url，在其后追加 event_type={event_type}；若上游提供金额，再追

加 currency_amount={currency_amount}，然后以 HTTP GET 回传。

注意：currency_amount 保持上游原始十进制单位，SCX 不自动换算为“分”；媒体不得按快手 amount 字段解析。

例如，媒体上报的原始 callback_url 为：

 https://media.example.com/ocpx/convert?request_id=clk_202608160001

激活回调：

 https://media.example.com/ocpx/convert?request_id=clk_202608160001&event_type=1

付费回调（有金额时）：

 https://media.example.com/ocpx/convert?request_id=clk_202608160001&event_type=5&currency_amount=123.45


 请求参数：

event_type     用户行为类型，整数 1～19，必传。

currency_amount       支付相关金额，可选，非负十进制数。

媒体回调地址必须为可解析的公网 HTTP/HTTPS URL；应在 5 秒内返回 HTTP 200 或 204，响应体内容会被忽略。
