# 个人中心页面

## 功能概述

个人中心页面 (`profile.vue`) 提供了用户个人信息管理的完整功能，包括：

### 1. 用户基本信息管理

- **显示信息**：头像、用户名、昵称、手机号、邮箱、性别、地区、详细地址
- **编辑功能**：通过弹窗形式编辑所有基本信息
- **头像上传**：支持头像上传和预览
- **表单验证**：对昵称、邮箱、手机号等字段进行格式验证

### 2. 密码管理

- **修改密码**：支持原密码验证的新密码修改
- **安全验证**：需要输入原密码才能修改
- **密码确认**：新密码需要输入两次确认
- **密码强度**：新密码长度不少于6位

### 3. 第三方账号绑定

- **微信绑定**：支持微信账号绑定和解绑
- **状态显示**：清晰显示绑定状态（已绑定/未绑定）
- **操作按钮**：根据绑定状态显示不同的操作按钮
- **弹窗授权**：微信绑定通过弹窗进行授权

## 页面结构

```
个人中心页面
├── 左侧用户信息卡片
│   ├── 头像和基本信息
│   └── 联系方式等详细信息
└── 右侧功能区域
    ├── 基本信息标签页
    │   ├── 信息展示
    │   └── 编辑按钮
    └── 账号安全标签页
        ├── 密码管理
        └── 第三方账号绑定
```

## 技术特性

### 响应式设计

- 支持桌面端和移动端适配
- 使用Element Plus的栅格系统
- 移动端友好的布局调整

### 用户体验

- 加载状态提示
- 操作成功/失败消息反馈
- 表单验证实时提示
- 平滑的动画过渡效果

### 数据管理

- 与用户Store集成
- 实时更新用户信息
- 支持头像上传
- 第三方账号状态同步

## API接口

### 用户信息相关

- `getById(id)` - 获取用户详细信息
- `editObj(data)` - 更新用户基本信息
- `editPassword(data)` - 修改用户密码

### 第三方账号相关

- `bindOpenId(data)` - 绑定第三方账号
- `unbindSocialAccount(userId, accountType)` - 解绑第三方账号
- `getByType(type)` - 获取第三方平台配置

## 路由配置

页面路由配置在 `apps/web-ele/src/router/routes/modules/system.ts` 中：

```typescript
{
  name: 'UserProfile',
  path: '/user/profile',
  component: () => import('#/views/system/user/info/profile.vue'),
  meta: {
    icon: 'lucide:user-check',
    title: '个人中心',
    hideInMenu: true,
  },
}
```

## 使用方式

1. **直接访问**：通过URL `/system/user/profile` 访问
2. **菜单导航**：在用户管理模块中添加个人中心入口
3. **用户下拉菜单**：在用户头像下拉菜单中添加个人中心选项

## 注意事项

1. **权限控制**：页面需要用户登录状态
2. **数据同步**：修改信息后会同步更新Store中的用户信息
3. **第三方绑定**：微信绑定需要后端配置相应的AppID
4. **文件上传**：头像上传需要配置正确的上传接口地址
