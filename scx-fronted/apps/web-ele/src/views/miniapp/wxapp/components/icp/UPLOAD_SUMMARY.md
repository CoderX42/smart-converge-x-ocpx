## 上传功能特性

### Upload.vue 组件特性
- **文件类型支持**：图片(JPG、PNG、GIF、WEBP、SVG)和视频
- **文件大小限制**：图片2MB，视频50MB
- **上传数量控制**：支持单文件和多文件上传
- **自动验证**：上传前自动验证文件格式和大小
- **错误处理**：完善的错误提示和处理
- **成功反馈**：上传成功后自动更新数据

## 技术实现

### 数据流
1. 用户选择文件 → Upload组件验证
2. 验证通过 → 调用上传API
3. 上传成功 → 更新formData对应字段
4. 触发v-model更新 → 父组件数据同步

### 错误处理
- 文件格式错误：提示支持的格式
- 文件大小超限：提示大小限制
- 上传失败：显示错误信息
- 网络错误：自动重试机制

### 安全性
- 文件类型白名单验证
- 文件大小限制
- 上传数量限制
- 服务器端二次验证

## 使用示例

```vue
<template>
  <!-- 材料上传 -->
  <Materials
    :form-data="formData"
    :is-disabled="isDisabled"
    :app-id="appId"
  />
  
  <!-- 证件照片上传 -->
  <Upload
    v-model="formData.subjectJson.organizeInfo.certificatePhoto"
    :app-id="appId"
    :limit="3"
    :disabled="isDisabled"
    type="image"
    icp-order-field="subjectJson.organizeInfo.certificatePhoto"
  />
</template>
```
