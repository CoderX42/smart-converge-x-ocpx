# 智汇广告平台品牌标识

当前品牌标识采用用户提供的最终图片稿。项目代号保留为 **Smart Converge X**，对外品牌名为 **智汇广告平台**。

方形图标中的数据曲线、增长箭头和统计元素表达广告数据汇聚、智能分析与持续增长。

## 文件

- `scx-logo-source.png`：用户提供的原始图片，未经裁切。
- `scx-logo-horizontal.png`：去除多余留白后的横版组合标。
- `scx-logo-icon.png`：从原图精确裁切的方形图标。
- `../../scx-fronted/apps/web-ele/public/static/logo.png`：管理后台实际使用的方形图标。

## 色彩

| 用途   | 色值      |
| ------ | --------- |
| 主蓝   | `#0866F5` |
| 深蓝   | `#061542` |
| 增长紫 | `#7A25FF` |
| 数据青 | `#36D7F3` |

## 使用规范

- 图标四周至少保留图标宽度 `1/8` 的净空。
- 32px 以下只使用方形应用图标，不使用横版文字。
- 不拉伸、不旋转、不改变原图色彩，不在复杂图片上直接叠加。
