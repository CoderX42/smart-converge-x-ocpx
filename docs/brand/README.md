# Smart Converge X 品牌标识

## 设计概念

Logo 名称为 **Convergence X**。两条数据流在中心汇聚为字母 `X`，主路径继续向右上方延伸，表达广告投放、事件归因、数据汇聚与可衡量增长。

## 文件

- `scx-logo-horizontal.svg`：标准横版组合标，白色背景。
- `scx-logo-monochrome.svg`：单色版本，用于打印或不支持渐变的场景。
- `scx-logo-preview.svg`：品牌标识展示与小尺寸预览。
- `../../scx-fronted/apps/web-ele/public/static/logo.svg`：管理后台实际使用的方形应用图标。

## 色彩

| 用途 | 色值 |
| --- | --- |
| 智汇蓝 | `#0758E8` |
| 汇聚靛 | `#4F46E5` |
| 增长紫 | `#7C3AED` |
| 数据青 | `#67E8F9` |
| 深色文字 | `#0F172A` |

## 使用规范

- 图标四周至少保留图标宽度 `1/4` 的净空。
- 32px 以下只使用方形应用图标，不使用横版文字。
- 不拉伸、不旋转、不改变渐变方向，不在复杂图片上直接叠加。
- 单色印刷使用 `scx-logo-monochrome.svg`。
