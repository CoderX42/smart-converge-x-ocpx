# 12 API、消息与集成规范

## 1. 基本原则

- 管理面使用版本化 REST API；高频事件使用专用接入 API；内部异步协作用事件消息。
- 对外契约与内部模型隔离，所有外部协议通过适配层转换。
- 写操作幂等、错误可分类、变更向后兼容、每个请求可追踪。
- OpenAPI、JSON Schema/Protobuf 和契约测试是接口事实来源；文档示例不得替代机器可校验契约。

## 2. HTTP 规范

| 项目 | 约定 |
| --- | --- |
| 前缀 | `/api/v1`；事件入口可为 `/events/v1`。 |
| 标识 | 不透明字符串 ID，禁止客户端推断数据库自增序列。 |
| 时间 | ISO-8601 UTC，毫秒精度。 |
| 金额 | 整数字符串或整数最小单位，响应附币种。 |
| 分页 | 游标分页优先；后台低量列表可用 page/size。 |
| 排序 | 明确字段白名单，默认排序稳定并包含 ID。 |
| 过滤 | 查询参数可组合；复杂报表使用 POST 查询但不得产生副作用。 |
| 幂等 | `Idempotency-Key` + 调用方作用域，保存请求哈希和最终结果。 |
| 追踪 | 接受/生成 `X-Request-Id`，响应返回 trace 标识。 |

## 3. 认证与签名

控制台使用 OIDC/JWT，短访问令牌与可撤销刷新令牌。机器接口使用 App ID + HMAC-SHA256 或双方确认的非对称签名，包含 HTTP 方法、规范化路径、时间戳、nonce 和 body hash。签名版本写在请求头，支持密钥轮换。

## 4. 统一响应与错误

```json
{
  "requestId": "req_01...",
  "code": "VALIDATION_FIELD_INVALID",
  "message": "字段校验失败",
  "details": [{"field": "dailyBudget", "reason": "must_be_positive"}],
  "data": null
}
```

| HTTP | 使用场景 |
| --- | --- |
| 200/201/202 | 查询/创建/异步接收成功。 |
| 400 | 格式或字段错误。 |
| 401/403 | 未认证/无权限或资源不属于当前主体。 |
| 404 | 资源不存在；避免泄露其他主体资源。 |
| 409 | 状态冲突、版本冲突或幂等键请求体不一致。 |
| 422 | 语法正确但违反业务规则。 |
| 429 | 限流，返回建议重试时间。 |
| 5xx | 平台异常；调用方可按策略重试。 |

错误码必须稳定，不使用自然语言做程序判断。

## 5. 并发控制

可编辑资源返回 `version`/ETag；更新使用 `If-Match` 或显式版本号。版本不一致返回 409，并提供重新读取提示。状态迁移使用专用命令接口，避免通过通用 PATCH 绕过校验。

## 6. 异步消息信封

```json
{
  "messageId": "msg_01...",
  "eventType": "attribution.completed",
  "schemaVersion": "1.0",
  "aggregateType": "attribution",
  "aggregateId": "attr_123",
  "occurredAt": "2026-08-01T08:00:01Z",
  "producer": "attribution-service",
  "traceId": "...",
  "payload": {}
}
```

生产者使用 Outbox 或等价机制保证数据库状态和消息发布一致。消费者以 `consumer + message_id` 幂等；业务顺序需要时按聚合 ID 分区。消息不得携带不必要的敏感明文。

## 7. Webhook

- Webhook 配置包含 URL、事件类型、签名密钥版本、启停状态、超时和重试策略。
- 每次投递有唯一 delivery_id；请求含时间戳、delivery_id、事件 ID 和签名。
- 2xx 视为成功；3xx 默认不跟随；429/5xx 可重试；其他 4xx 进入失败调查。
- 提供测试发送、投递日志、暂停、重放和密钥轮换。

## 8. 版本与兼容

- 新增可选字段属于兼容变更；删除、重命名、改变类型/语义属于破坏性变更。
- 消费者必须忽略未知字段；生产者不得复用已废弃字段表达新语义。
- 公开 API/消息至少提供一个发布周期的弃用通知、双写/双读窗口和迁移指南。
- Schema Registry 或仓库契约测试阻止不兼容消息上线。

## 9. 适配器接口

每个媒体/广告主适配器提供：协议元数据、请求校验、标准模型映射、签名/验签、事件映射、响应解析、可重试判断、脱敏日志、契约测试样例和沙箱配置。核心业务不允许出现合作方特有字段分支。
