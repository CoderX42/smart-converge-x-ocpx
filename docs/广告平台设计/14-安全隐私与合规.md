# 14 安全、隐私与合规

## 1. 安全目标

保护资金、广告主与媒体配置、设备/用户标识、业务转化、密钥和审计证据。所有安全控制同时覆盖管理 API、事件入口、消息、缓存、日志、导出和后台任务。

## 2. 数据分类

| 级别 | 示例 | 处理要求 |
| --- | --- | --- |
| S4 极敏感 | 密钥、令牌、密码、支付凭据 | 专用密钥系统、禁止日志/导出、最小权限。 |
| S3 敏感 | 手机号、原始设备标识、精确 IP、订单信息 | 字段加密/令牌化、严格审计、最短保留。 |
| S2 内部 | 出价、预算、合同价、归因明细 | 访问控制、传输/存储加密、受控导出。 |
| S1 一般 | 公开素材、聚合公开信息 | 完整性和可用性保护。 |

默认不采集无法说明用途的数据。新增敏感字段必须记录用途、合法性、保留期、访问角色和删除方式。

## 3. 威胁与控制

| 威胁 | 控制 |
| --- | --- |
| 跨主体越权 | 服务端资源归属校验、默认拒绝、对象级授权测试。 |
| 回调伪造/重放 | HMAC/非对称签名、时间戳、nonce、幂等键、IP 白名单。 |
| 密钥泄露 | KMS/Vault、轮换、作用域、扫描、脱敏、紧急吊销。 |
| SQL/命令/模板注入 | 参数化、白名单、隔离执行、输入长度和格式限制。 |
| SSRF | Webhook URL 验证、DNS/IP 策略、私网阻止、出站代理。 |
| 恶意素材 | 类型嗅探、病毒扫描、大小限制、对象存储隔离、安全渲染。 |
| 账务篡改 | 只追加流水、职责分离、审计、每日勾稽和复核。 |
| 日志泄露 | 字段分级、结构化脱敏、禁止原始 payload 默认落日志。 |

## 4. 身份与权限

- 管理账户支持强密码、登录限速、异常登录告警和 MFA 预留。
- 高权限、财务和密钥操作建议强制 MFA。
- 服务身份与用户身份分离；每个服务使用独立最小权限凭据。
- 离职/停用立即撤销会话、API Key 和后台任务权限。

## 5. 密钥生命周期

创建 → 激活 → 双密钥轮换 → 旧密钥过渡 → 撤销 → 审计归档。密钥只显示一次；数据库只保存密钥引用或不可逆校验材料。异常泄露可跳过过渡期紧急撤销，并触发影响分析。

## 6. 隐私生命周期

采集前定义目的 → 最小化采集 → 脱敏/加密 → 按目的授权使用 → 到期删除或匿名化 → 留存删除证据。设备/用户标识必须与广告归因用途绑定，不能自动扩展为画像用途。

## 7. 审计

审计记录包含谁、何时、从何处、对什么资源、执行什么动作、前后差异、结果、原因和 trace_id。审计日志防篡改、独立保留；普通管理员不能删除。

## 8. 安全发布门

依赖漏洞、密钥扫描、SAST、鉴权测试、敏感日志测试和关键威胁模型评审通过后才能生产发布。新外部接入还需协议验签测试、出站安全评估和限流压测。

## 9. 合规待决事项

正式收集真实设备或个人信息前，必须由业务负责人确认服务地域、数据主体、隐私政策、授权方式、数据保留期限、跨境要求和用户权利处理流程。本文件是工程基线，不替代专业法律意见。
