# 03 上游广告主与接入资料

> 状态：Draft
> 现场范围：参考站点未见独立广告主页；“上游客户/客户文档”仅在链接、任务和报表筛选中出现
> SCX 归属：复用 `AdxAdvertiser`、上游 Adapter 与现有对象存储能力

## 1. 需求证据与边界

| 证据 | 结论 |
|---|---|
| `现场实测` | 链接新增要求选择上游客户及客户文档；链接/任务/报表可按上游客户筛选 |
| `界面文案推断` | 客户文档用于指导参数、回调与联调，但不能证明参考站点如何存储 |
| `SCX仓库事实` | `AdxAdvertiser` 已有 adapter、bidUrl、Secret、账号/密码哈希、余额、状态、配置版本 |
| `SCX目标设计` | 保留 Advertiser 作为上游根聚合；接入资料使用受控文档引用和适配器能力声明 |

## 2. SCX 目标页面 `PAGE-ADX-ADVERTISER`

页面位于 `views/adx/advertiser/index.vue`，布局为筛选栏、列表、分页和右侧抽屉。

### 2.1 列表与筛选

| 类型 | 字段/控件 | 规则 |
|---|---|---|
| 筛选 | 名称/编码、Adapter、状态、是否配置文档 | 条件改变回第 1 页；服务端对象范围过滤 |
| 列 | 名称、编码、Adapter、接入地址掩码、资料版本、余额状态、状态、配置版本、更新时间 | Secret/账号不显示；URL 只显示 host + 掩码 |
| 空态 | 无数据/无权限/筛选无结果分别展示 | 有创建权限才显示新增入口 |

### 2.2 按钮

| ID | 触发条件 | 执行流程 | 成功/失败 |
|---|---|---|---|
| `BTN-ADV-SEARCH` | 有查看权限 | GET 列表 | 更新列表；失败保留筛选并可重试 |
| `BTN-ADV-ADD` | `adx:advertiser:add` | 打开空抽屉 | 不发请求 |
| `BTN-ADV-EDIT` | 行可见且有编辑权限 | 拉取详情；Secret 只返回 configured | 更新成功 Toast、刷新当前页；版本冲突提示刷新 |
| `BTN-ADV-DOCS` | 有资料查看权限 | 打开资料版本抽屉 | 只提供受控预览/下载 |
| `BTN-ADV-SECRET-ROTATE` | 独立密钥权限 + 二次确认 | 写入新 Secret，旧值进入短暂重叠期 | 只返回 configured/revision，不返回新旧 Secret；失败不撤销旧 Secret |
| `BTN-ADV-STATUS` | 无活动阻塞或允许暂停 | 启用/禁用确认 | 禁用后新发布校验失败；已发布快照按明确策略处理 |

### 2.3 新增/编辑抽屉 `POP-ADV-FORM`

| 字段 | 类型 | 必填/校验 | 条件 |
|---|---|---|---|
| 名称 | 文本 | 必填，1–64，范围内唯一 | 始终 |
| 编码 | 文本 | 创建必填，`[a-z0-9_-]{2,32}`，创建后不可改 | 始终 |
| Adapter | 下拉 | 必填；来自服务端注册表 | 始终 |
| 上游地址 | URL | Adapter 要求时必填；仅 HTTPS/允许域 | 按 capability |
| 账号 | 文本 | 按 Adapter；读取时掩码 | 按 capability |
| 密码/Secret | 密码 | 新增或轮换填写；永不回显 | 按 capability |
| 初始余额/币种 | 金额/下拉 | 金额非负；币种创建后不可改 | 开启账务时 |
| 接入资料 | 文件引用 | 白名单类型/大小；病毒扫描后可用 | 可选/按 Adapter |
| 状态 | 开关 | 默认禁用，完成校验后启用 | 始终 |

关闭方式为 X/取消/Esc；表单有改动时弹出未保存确认。提交中禁止重复点击。资料上传成功但业务保存失败时，临时对象由定时任务清理。

### 2.4 接入资料抽屉 `POP-ADV-DOCS`

展示文件名、资料类型、版本、摘要、上传者、扫描状态、创建时间和适配器能力映射；操作包括预览、下载、上传新版本、设为当前、停用。外链文档只允许经过服务端重定向/短期签名地址，不能在表格直接暴露永久 OSS URL。

## 3. 领域与表设计

保留 `scx_adx_advertiser`，建议补充：

| 字段 | 说明 |
|---|---|
| `code` | 稳定业务编码，唯一 |
| `adapter_key` / `adapter_version` | 已选择适配器与能力版本 |
| `credential_ref` | 加密凭据引用，不存明文 |
| `document_set_id` | 当前资料集合 |
| `status` | `DISABLED/ACTIVE/ARCHIVED` |
| `config_version` | 乐观锁与发布冻结版本 |

新增 `scx_adx_integration_document`：`id, owner_type, owner_id, document_type, object_key, file_name, content_type, size, sha256, version, scan_status, status, created_by, created_at`。唯一索引 `(owner_type, owner_id, document_type, version)`；`object_key` 不通过普通详情接口返回。

适配器能力由代码注册表提供，不建立任意脚本表：`requiresBidUrl/supportsCallback/authTypes/eventVocabulary/maxTimeoutMs`。发布快照记录 adapter key/version 和 credential revision。

## 4. API

| 方法 | 路径 | 权限 | 说明 |
|---|---|---|---|
| GET | `/adx/advertisers` | `adx:advertiser:view` | 分页筛选 |
| POST | `/adx/advertisers` | `adx:advertiser:add` | 幂等创建，默认禁用 |
| GET | `/adx/advertisers/{id}` | view + scope | 详情；凭据仅返回 configured/revision |
| PUT | `/adx/advertisers/{id}` | `adx:advertiser:edit` | 携带 version |
| POST | `/adx/advertisers/{id}/credentials:rotate` | `adx:advertiser:credential` | 二次认证；响应只含 configured/revision |
| POST | `/adx/advertisers/{id}/status` | `adx:advertiser:status` | 启禁用，检查引用 |
| GET/POST | `/adx/advertisers/{id}/documents` | `adx:advertiser:document:*` | 资料列表/登记上传结果 |

创建请求示例字段：`name, code, adapterKey, bidUrl, credentialInput, currency, documentIds`。响应不返回 `credentialInput`。URL/凭据改变会把依赖 MonitorRoute 标记为待重发，但不会静默改变已发布快照。

## 5. 跨模块联通

- Product 创建必须选择同范围 ACTIVE Advertiser。
- AppLink 的 Advertiser 必须与 Product 一致；客户文档从 Advertiser 当前有效资料中选择并冻结版本。
- Task 通过 Product/AppLink 间接确定上游广告主，禁止选择冲突客户。
- 发布服务校验 Adapter capability、凭据 revision、资料/事件映射；运行时只读快照引用。
- 报表按 advertiserId 聚合；余额/账务与事件事实分离，不用报表反推余额。

## 6. 权限、安全与审计

权限码：`adx:advertiser:view/add/edit/status/credential/document:view/document:edit`。Credential 权限不能由普通编辑隐式获得；对象范围按 advertiser 过滤。

- Secret 只写不回显；轮换使用加密存储和 revision，日志仅记“已轮换”；自由文本原因会对 key/token/长令牌模式脱敏后再审计。
- 接入 URL 防 SSRF；联调请求必须走 ADR-002 调试工作台和一次性授权，不从浏览器直接代理。
- 文档下载短期授权，记录下载人和对象；文件扫描通过前不可预览或发布。

## 7. 迁移、可观测与验收

- 先为存量 Advertiser 回填 code/configVersion，再增加唯一约束；凭据迁移验证哈希/加密状态，不导出明文。
- 指标：创建/更新冲突数、凭据轮换成功率、资料扫描失败、Adapter 校验失败、依赖路由待重发数。

| 层级 | 必测 |
|---|---|
| UI | 新增/编辑条件字段、Secret 空值不覆盖、未保存退出确认 |
| API | 幂等创建、版本冲突、非法 URL、Adapter 不支持字段、凭据不回显 |
| DB | code 唯一、资料版本唯一、归档引用保护、审计无 Secret |
| 权限 | 普通编辑者不能轮换凭据；范围外 ID 返回不泄露存在性的拒绝 |
| 集成 | Advertiser 变更使依赖路由进入待发布；旧快照仍可审计 |
| 异常 | 上传成功但保存失败清理临时对象；扫描失败不能设为当前 |

依赖路由采用“待重发”语义：Advertiser 配置、凭据或当前资料改变时，只标记已发布 Monitor `republish_required=1` 并保留现有 URL、路由状态和已发布版本；下一次显式发布才冻结新的 Adapter、credential revision 和 document revision。资料下载由服务端受控流式返回，不向列表或详情暴露 `object_key`/永久 URL。当前资料及已被发布快照冻结的资料版本不可停用。
