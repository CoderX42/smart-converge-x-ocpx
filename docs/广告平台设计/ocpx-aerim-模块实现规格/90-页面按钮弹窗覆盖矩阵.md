## 8. 状态覆盖与待验证项

| 状态 | 已观察 | SCX 验收要求 |
|---|---|---|
| Loading | 用户列表延迟加载、表格加载结构 | 每页骨架/单航班/可取消 |
| Empty | Task/部分查询空结果 | 区分初始空与筛选空 |
| Error | 未主动制造服务端错误 | 所有页面保留输入、重试、traceId |
| NoPermission | 未切换角色 | 菜单/按钮/API/对象范围四层验收 |
| Validation | 数值最小值、条件字段可见 | 字段/动态行/跨对象校验和服务端重复校验 |
| SubmitSuccess/Failure | 有副作用动作均未执行 | Toast、刷新、关闭、错误定位、幂等、并发 |
| Export/Download | 未执行 | 异步任务、权限、过期、审计 |

实施时任何控件新增或删除都要同步本矩阵；验收证据至少包含 UI case、API case、DB invariant、权限 case 和异常 case 的编号。
