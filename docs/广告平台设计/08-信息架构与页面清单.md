## 3. 通用交互规则

- 列表必须支持明确的空状态、加载状态、权限不足和数据延迟状态。
- 高风险操作展示影响对象、原因输入和二次确认，不能只显示“确定删除”。
- 状态使用“业务状态 + 原因”；例如“已暂停：余额不足”，避免只有颜色。
- 报表显示数据时区、口径版本、最后更新时间和是否为预估值。
- 所有金额同时标明币种和单位；输入金额在提交前显示格式化后的确认值。
- 敏感字段默认脱敏；明文查看需要权限、原因和审计。
- 任务型操作返回任务 ID，可查看进度和失败明细，不让用户重复点击制造重复任务。

## 4. 首版页面验收

每个页面至少具备：权限控制、搜索/筛选、分页或合理虚拟滚动、错误提示、空状态、操作反馈、审计关联和响应式最低可用布局。核心投放与资金页面还需覆盖并发编辑冲突、过期数据版本和防重复提交。
