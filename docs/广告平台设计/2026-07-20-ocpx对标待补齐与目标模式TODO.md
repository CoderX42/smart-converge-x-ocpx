> 更新时间：2026-07-20  
> 目标：在不降低 SCX 服务端权限、审计和数据安全边界的前提下，使菜单结构与运营功能达到 `ocpx.aerim.cn` 当前可见后台的等价水平。  
> 证据来源：2026-07-20 竞品登录后的实时页面核对、[2026-07-15 功能审计报告](2026-07-15-ocpx-aerim-功能审计报告.md)、当前仓库代码与迁移脚本。  
> 非目标：复制竞品的前端实现、路由命名、权限缺陷、真实媒体凭据或业务数据。

## 1. 使用规则

- 本文的“已具备”仅表示当前仓库中存在对应代码或菜单种子；目标环境仍须逐页验收。
- 本文的“待补齐”是对标目标，不自动改变已接受的 MVP-A 范围；涉及真实媒体接入、计费、审减、预算、风控、设备标识或生产回传时，必须先完成独立决策与设计。
- 竞品存在“隐藏菜单仍可直接访问路由”的观察。SCX 不得复刻该行为：菜单可见性、接口权限、媒体范围、任务范围和导出范围必须分别在服务端校验。
- 每个 ToDo 完成后必须更新“状态、证据、遗留风险、下一项”，不能以页面截图替代接口、权限和数据验证。

## 2. 目标菜单模式

目标为按运营人员的工作流组织菜单，而不是将所有能力平铺在“投放配置”下。

```text
仪表盘
产品管理
链接管理
媒体管理
任务管理
RTA 管理
数据管理
├─ 数据汇总
├─ 产品汇总
├─ 链接汇总
├─ 任务汇总
└─ 媒体汇总
系统管理
└─ 用户管理
工具箱
└─ DP 转换
```

### 2.1 菜单映射与差距

| 目标菜单 | 目标能力 | 当前 SCX 对应能力 | 待补齐点 | 优先级 |
|---|---|---|---|---|
| 仪表盘 | 点击、激活、次留、首活、付费指标卡与趋势 | `效果概览` 页面 | 统一入口、竞品同类指标卡、趋势与口径说明 | P0 |
| 产品管理 | 产品搜索、新增、编辑、状态管理 | 主数据页产品视图 | 独立菜单/页面体验、状态与引用影响提示 | P0 |
| 链接管理 | 产品/客户/文档关联、链接类型、归档、今日概况、事件映射 | 追踪链接页 | 今日概况、归档筛选、事件单价/限量可视化、竞品式运营字段 | P0 |
| 媒体管理 | 媒体渠道、媒体文档、渠道用户绑定 | 媒体渠道、渠道用户、文档页 | 以单一入口串联三类主数据与筛选 | P0 |
| 任务管理 | 任务配置、监测地址、今日概况、时报/日报/联调/明细入口 | 监测任务页、报表和明细页 | 任务行内运营入口与统一跳转参数 | P0 |
| RTA 管理 | RTA 配置、启停、请求量、成功率、时报/日报 | RTA 配置/决策/日志 | 运营指标、状态操作和报表入口 | P0 |
| 数据管理 | 五类汇总、筛选、分页、导出 | 五类汇总页与导出 | 对齐指标字段、筛选一致性、审减导出边界 | P0 |
| 系统管理 | 用户、角色、任务授权、状态、个人中心 | 系统用户/RBAC、任务授权 | 面向广告运营的任务授权入口与用户状态闭环 | P1 |
| 工具箱 | DP 转换/短链工具 | 短链与 DP 工具 | 从投放配置迁为独立菜单与独立入口 | P1 |
| 运行态管理 | 回传、导出、异步队列运行状态 | 回传作业、导出任务、任务中心 | 统一队列大盘：等待、执行、成功、失败、延迟、暂停、死信 | P1 |
