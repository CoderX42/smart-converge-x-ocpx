# 05 安全、运维、测试与研发计划

## 1. 权限与安全

### 1.1 角色

| 角色 | 权限范围 |
| --- | --- |
| 平台超级管理员 | 全局配置、账户、资金、审计和紧急处置。 |
| 平台运营 | 媒体、投放审核、投放调整、报表；不可直接改账。 |
| 财务 | 充值、对账、结算、发票；不可修改投放策略。 |
| 风控审核 | 审核、黑白名单、申诉；不可访问完整敏感明文。 |
| 广告主管理员 | 本广告主的账户、投放、创意、报表和回调配置。 |
| 广告主只读 | 本广告主的报表与账单只读。 |
| 媒体管理员 | 本媒体广告位、数据、回传配置和结算信息。 |

### 1.2 数据安全基线

- 设备标识、手机号、订单号等敏感数据最小化采集；报表中使用聚合数据。
- 敏感标识哈希化或字段级加密；密钥只存密钥管理系统，禁止写入代码、日志和导出文件。
- 管理操作全量审计；导出、资金、密钥、白名单和权限变更要求二次确认。
- 回调接口强制 HTTPS、签名、重放保护、限流和 IP 白名单。
- 明确数据保留与删除策略：原始事件、明细、聚合、财务与审计的保留时长分别配置。

## 2. 运维与可观测性

### 2.1 必备监控

请求 QPS、P50/P95/P99 延迟、超时率、错误率、限流数、事件积压、消费延迟、去重率、回调成功率、预算超限拦截、账务不平率、数据延迟、数据库连接池、缓存命中率、磁盘和 JVM/进程资源。

### 2.2 告警规则

| 场景 | 告警阈值示例 | 处置 |
| --- | --- | --- |
| 事件接入失败 | 5 分钟错误率 > 1% | 降级、检查上游/网关、保留原始请求。 |
| 回调堆积 | 积压超过 10 分钟 | 扩容消费者、检查媒体端与死信。 |
| 报表延迟 | 分钟数据延迟 > 15 分钟 | 检查事件总线和聚合任务。 |
| 资金异常 | 日账务不平或余额为负 | 停止结算，启动对账与人工复核。 |
| 作弊异常 | 某媒体无效流量率突增 | 自动降权或暂停媒体，进入复核。 |

### 2.3 发布与灾备

- 使用开发、测试、预生产、生产环境隔离；生产变更必须审批与可回滚。
- 实时服务滚动/金丝雀发布，按媒体或流量百分比灰度。
- 数据库每日备份并验证恢复；分析库和事件总线按 RPO 配置副本与归档。
- 建立故障手册：外部媒体故障、广告主回调故障、消息积压、数据延迟、账务异常、密钥泄露。

## 3. 测试与验收

### 3.1 测试层级

| 类型 | 必测内容 |
| --- | --- |
| 单元测试 | 出价、定向、频控、去重、归因、账务和签名规则。 |
| 集成测试 | 数据库事务、Redis 原子预算、消息幂等、外部适配器。 |
| 契约测试 | 媒体/广告主请求与回调字段、签名和错误码。 |
| 压力测试 | 峰值 QPS、限流、超时、消息积压恢复和缓存击穿。 |
| 安全测试 | 越权、重放、签名伪造、注入、敏感信息泄露和权限审计。 |
| UAT | 创建投放到结算的端到端业务闭环。 |

### 3.2 一期验收清单

- 可创建广告主、媒体、广告位、活动、计划、广告和已审核创意。
- 可按预算、定向、排期、频控和余额正确投放/拦截。
- 展示、点击、转化可验签、去重、归因并可查询处理结果。
- 媒体转化回传支持失败重试、死信和人工重放。
- 报表能与明细和账单在约定口径下对平。
- 余额变化可从流水完整追溯；关闭账单只能冲正。
- 不同广告主与媒体不能越权访问对方数据。
- 高峰压测下关键接口满足约定时延，无确认事件丢失。

## 5. 项目启动决策

在编码前必须确定以下事项：首批媒体和广告主的协议；广告格式（展示、信息流、视频、激励视频、搜索等）；计费与结算主体；归因窗口与口径；数据合规地域；预计峰值 QPS；以及资金账户是否接入实际支付。根据 ADR-0001，一期不包含实时竞价。
