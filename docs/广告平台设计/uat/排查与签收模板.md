# 回执排查与第三方签收模板

## 排查步骤

1. 收集 `receiptId`、`eventId`、渠道请求时间、HTTP 状态，不收集密钥或原始设备号。
2. 查询回执接口，核对 `BUFFERED/ACCEPTED/PROCESSED/FAILED`。
3. 核对 Redis Stream 长度、PEL、消费者、DLQ 与最大投递次数。
4. 核对 Raw Event、Outbox、归因结果、Callback Job 的数量及状态，不读取密钥密文/IV。
5. 对 Postback 核对 payload hash、幂等键、key version、HTTP 状态和错误码。
6. 故障恢复后记录积压归零时间，并执行数据库/Stream/回调端对账。
