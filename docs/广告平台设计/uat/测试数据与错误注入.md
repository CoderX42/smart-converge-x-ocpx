# 测试数据与错误注入

仅使用高基数合成的 SHA-256 设备值。Android 选择 `OAID`，iOS 选择 `IDFA`；固定设备并发只用于
点击验重场景，不得使用真实广告标识。

| 场景 | 注入方式 | 预期 |
|---|---|---|
| 签名错误 | 修改正文但复用签名 | 401，不写入 Buffer |
| 时钟过期 | 时间戳偏移超过 180 秒 | 401 |
| Nonce 重放 | 相同 nonce 再请求 | 401 |
| 事件幂等 | 相同 eventId 与相同正文 | 200，原 receiptId |
| 事件冲突 | 相同 eventId 与不同正文 | 409 |
| Redis 中断 | 请求前停止 Redis | 503，不错误确认 |
| Pending 恢复 | 消费后、ACK 前杀 Worker | 新 Worker XAUTOCLAIM 后落库 |
| 提交前崩溃 | MySQL 事务提交前杀 Worker | 消息保留，恢复后重试 |
| 提交后崩溃 | 提交后、ACK 前杀 Worker | 幂等落库并 ACK |
| 损坏消息 | Stream 注入非法 JSON | 原子写 DLQ 并 ACK 原消息 |
| Postback 重试 | 回调端依次 500/500/200 | 1、2 分钟后重试，正文与幂等键不变 |
| Postback 死信 | 连续五次失败 | DEAD，可授权人工重放 |
| 重定向 | 回调端返回 302 | 不跟随，按失败处理 |

DLQ 重放前记录源消息 ID、错误码、审批人和目标媒体/任务；重放成功后不得删除原 DLQ 事实。
