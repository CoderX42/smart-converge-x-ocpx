# 测试数据与错误注入

只使用合成事件 ID、点击 ID 和设备值，不得使用真实广告标识或真实 Secret。

| 场景 | 注入方式 | 当前最小版本预期 |
|---|---|---|
| 正常 Feedback | 正确四实体关系、凭据与上游 Mock | 上游成功后返回 202，写 SUCCESS 日志 |
| 签名错误 | 修改正文但复用签名 | 401，不进入外发 |
| 时钟过期 | 时间戳偏移超过 5 分钟 | 401 |
| 密钥版本错误 | 修改 `X-OCPX-Key-Version` | 401 |
| 关系错误 | mediaCode 与任务媒体不一致 | 404 |
| Adapter 不支持事件 | 提交不支持事件 | 422 |
| 上游拒绝 | 上游返回非成功业务码或超时 | 502，写 FAILED Feedback 日志 |
| 正常 Callback | 使用 Feedback 生成的签名 ext | 下游成功后返回广告主协议成功响应，写 SUCCESS 日志 |
| 下游拒绝 | Callback Mock 返回 500 | 广告主收到失败响应，写 FAILED Callback 日志 |
| 重定向 | 合作方返回 302 | 不跟随，按 Adapter 规则判为失败 |
| 重复请求 | 再次发送相同 event_id | 可能再次外发；当前没有服务端幂等表 |

当前不测试 Redis Pending、自动重试、DLQ 或人工重放，因为这些能力已退出最小版本。
