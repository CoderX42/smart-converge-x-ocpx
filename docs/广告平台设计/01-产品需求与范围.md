# 01 产品需求与范围

## 1. 产品定位

平台连接广告主需求与媒体流量，负责投放配置、流量分发、展示/点击/转化采集、归因优化、报表、财务对账和风控。核心目标是在可控成本下提升广告主转化结果，并保证媒体、广告主与平台三方的数据可核验。

### 1.1 业务对象

| 对象 | 说明 |
| --- | --- |
| 平台运营 | 维护全局规则、媒体接入、审核、风控、结算和数据质量。 |
| 广告主 | 创建投放活动、充值、查看数据、接收线索或转化。 |
| 代理商 | 长期可代管广告主投放、预算与报表；是否进入首版是 M0 待决事项，默认延期，不预建返点与授信模型。 |
| 媒体 | 提供广告位/流量，接收投放配置，回传曝光、点击及接收转化回传。 |
| 财务 | 对账、出账、确认收付款、开票。 |
| 审核员 | 审核广告主资质、创意、落地页和异常申诉。 |

## 3. 投放管理详细需求

### 3.1 层级模型

`广告主 → 活动 Campaign → 计划 Ad Group → 广告 Ad → 创意 Creative`

| 层级 | 主要字段 | 职责 |
| --- | --- | --- |
| 活动 | 名称、业务目标、总预算、投放日期、状态 | 统一定义营销目标和预算上限。 |
| 计划 | 计费方式、优化目标、出价策略、日预算、排期 | 决定投放和优化策略。 |
| 广告 | 定向、频控、媒体/广告位范围、落地页 | 定义一组可投放对象。 |
| 创意 | 格式、素材、文案、跳转地址、审核状态 | 定义实际展示内容。 |

### 3.2 支持的计费与优化

| 类别 | 必须支持 |
| --- | --- |
| 计费 | CPM、CPC、CPA；费用可按媒体结算规则和广告主扣费规则分别配置。 |
| 优化 | 优化展示、点击、激活、注册、付费；二期支持目标 CPA、目标 ROI、最大转化。 |
| 预算 | 活动总预算、计划日预算、预算平滑、超预算停止、余额不足停止。 |
| 出价 | 固定出价、最高出价、目标成本出价；所有自动调价保留版本和调整原因。 |

### 3.3 状态

| 对象 | 状态 |
| --- | --- |
| 账户 | 待审核、正常、冻结、关闭。 |
| 活动/计划/广告 | 草稿、待审核、审核拒绝、待开始、投放中、已暂停、已结束、预算耗尽、异常停止。 |
| 创意 | 草稿、待审核、审核通过、审核拒绝、已下线。 |
| 媒体/广告位 | 待接入、测试中、启用、暂停、下线。 |

## 4. 报表与运营需求

### 4.1 必备指标

展示、有效展示、点击、有效点击、CTR、消耗、eCPM、CPC、转化数、CVR、CPA、收入、毛利、ROI、去重设备数、无效流量率、回传成功率、归因延迟。

### 4.2 必备维度

日期/小时、广告主、活动、计划、广告、创意、媒体、应用/站点、广告位、地域、设备、系统、网络、定向包、转化事件、计费方式。

### 4.3 运营控制台

- 总览：消耗、收入、毛利、转化、预警和待办审核。
- 投放监控：分钟级 QPS、填充率、胜率、预算消耗、回传成功率和异常趋势。
- 数据分析：任意合法维度组合查询、钻取、保存报表、导出。
- 运营动作：暂停/恢复、预算调整、出价调整、黑名单操作、补数/重放申请。

## 5. 范围边界

### 一期必须交付

账户权限、广告主资金账户、媒体/广告位、投放层级、素材审核、定向、频控、曝光/点击/转化采集、规则归因、基础 OCPX、报表、对账、开放回调和审计。

### 二期交付

OpenRTB、实时竞价策略、自动出价、机器学习特征与模型服务、反作弊评分、私有交易、更多媒体适配器。

### 不纳入首版

自助 SaaS 开户/订阅计费、跨企业多租户、广告联盟分润、CDP 全量能力、程序化保量交易、跨设备图谱、第三方数据交易市场。
