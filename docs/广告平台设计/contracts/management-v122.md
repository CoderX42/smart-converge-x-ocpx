# OCPX 原始请求审计退役契约 V122

## 退役范围

- Engine 不再采集、加密、写入或重放原始请求审计，不再创建本地 WAL。
- 管理端删除原始请求审计分页、详情和导出接口，前端删除对应页签。
- 数据库删除 `scx_ocpx_wire_audit_payload`、`scx_ocpx_wire_audit` 及两项专用权限。
- V119 脱敏流程日志、OCPX 事实表、计费、扣量和报表继续保持业务权威性。

## 发布顺序

1. 先部署并重启不含审计/WAL的新 Engine，确认 WAL 不再增长。
2. 备份数据库后前向执行 `V122__remove_full_wire_audit.sql`；不得修改或重放 V121。
3. 确认两张审计表和专用权限均不存在，再清理服务器遗留 WAL 文件。

## Callback 兼容

Callback URL 的 `kid`、活动密钥及历史密钥读取顺序继续保留，避免已生成链接在归因窗口内失效；这部分不写 WAL，也不依赖 V121 表。
