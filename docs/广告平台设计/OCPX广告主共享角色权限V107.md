# SCX 广告主共享角色全量权限管理 V107

## 决策

V107 在“广告主管理”工具栏增加全局“账号角色权限”入口，维护系统托管的固定共享角色 `ROLE_ADVERTISER`。配置不属于某一行广告主；所有现有及未来的 `sys_user.type=2` 广告主账号共同使用同一份权限。

- `ocpx:advertiser:role:manage` 只授予 `ROLE_ADMIN`，且永远不出现在广告主可选权限树中。
- `ocpx:advertiser:scope:all` 是独立的全量 OCPX 数据范围开关，不替代任何动作权限。
- 媒体、扣量规则及广告主新增/删除依赖全量范围；前端禁用不一致选择，后端再次拒绝。
- 未开启全量范围时，广告主账号仍由会话 `shopId` 限制为自身广告主，以及其推广链接、监测任务、报表和流程日志；具体可执行动作继续由 `@SaCheckPermission` 决定。
- 开启全量范围时，广告主账号可在已授权动作内访问全部 OCPX 五类对象；系统管理、非 OCPX 权限和本权限管理入口不能下放。
- 保存采用全量替换，服务端只接受有效 OCPX 白名单节点并自动补齐父级菜单。保存后清理菜单缓存并注销全部广告主账号会话，相关账号必须重新登录。

接口字段见 [V107 管理契约](contracts/management-v107.md)，架构决策见 [ADR-014](adr/ADR-014-广告主共享角色与全量数据范围.md)。通用用户/角色页面继续隐藏并禁止修改、删除或错误分配该托管角色。

## 初始化与发布

`V107__add_advertiser_shared_role_permissions.sql` 新增管理权限和全量范围权限，只把管理权限授予 `ROLE_ADMIN`，并把 `ROLE_ADVERTISER` 初始化为全部当前 OCPX 业务权限和全量范围。未来新增 OCPX 权限不会自动加入，必须从权限页面显式授权。

该初始化会扩大全部广告主账号权限，包括按已授予的删除权限执行广告主级联删除。正式应用前必须确认目标结构已依次完成至 V106，备份、盘点受影响账号、核对 SQL SHA-256 并取得明确授权；应用后重启/刷新服务端缓存并让广告主账号重新登录验收。源码、本地测试与隔离数据库验证不代表目标数据库、UAT 或生产已经发布。

紧急收口应通过本页面恢复只读或清空权限。不得改写已执行的 V107；后续数据库修复必须新增前向 SQL。
