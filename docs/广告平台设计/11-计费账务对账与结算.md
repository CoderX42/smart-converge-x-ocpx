# 11 计费、账务、对账与结算

## 1. 财务模型

系统区分三类事实：广告事件事实、计费事实和资金流水。事件通过规则后产生计费事实；计费事实经确认后产生资金流水。报表不能直接修改余额，原始事件也不等于可计费事件。

## 2. 金额约束

- 金额使用 `BIGINT` 最小货币单位，币种使用 ISO 代码；首版建议只允许单币种结算。
- 比率、税率和分成使用定点小数，明确精度与舍入模式。
- 舍入发生在合同约定层级（单事件、日汇总或账单），一经确定通过 ADR 固化。
- 所有写账请求有业务幂等键和唯一约束。

## 3. 计费模式

| 模式 | 广告主计费事件 | 必备条件 |
| --- | --- | --- |
| CPM | 有效且可计费展示 | 展示唯一、媒体/广告位有效、风控通过。 |
| CPC | 有效且可计费点击 | 点击唯一、关联有效投放、风控通过。 |
| CPA | 已确认归因转化 | 唯一转化、归因成功、事件类型匹配、质量确认。 |
| OCPX | 底层仍落为约定计费事实 | 优化目标不能替代合同计费口径。 |

广告主扣费价与媒体结算价分开记录，禁止用“扣量”替代合法、明确的结算规则。

## 4. 账户与流水

| 账户 | 方向 | 说明 |
| --- | --- | --- |
| 广告主可用余额 | 借/贷 | 充值增加，扣费减少。 |
| 广告主冻结余额 | 借/贷 | 预算预占或争议冻结。 |
| 媒体应付 | 贷方累计 | 可结算媒体成本。 |
| 平台收入/成本 | 会计映射 | 按财务确认口径入账。 |

流水类型至少包括：充值、授信、预占、释放、扣费、退款、人工调整、账单冲正、媒体应付确认、结算支付。每条流水含 `business_key`、账户、方向、金额、币种、发生前后余额、关联事实、操作者/系统任务和时间。

## 5. 预算与预占

- 一期配置投放可在计费事实确认时原子扣减预算与余额。
- M6 RTB 需在竞价/返回前预占预算，胜出/计费后确认，超时或失败释放。
- 活动总预算、计划日预算、账户余额和授信均需校验。
- 日预算按账户时区日切；跨时区修改需延后生效并审计。

## 6. 账单生命周期

`OPEN → PROVISIONAL → RECONCILING → CONFIRMED → CLOSED → SETTLED`

- OPEN：持续接收计费事实。
- PROVISIONAL：账期结束后的初步聚合，可处理迟到事件。
- RECONCILING：对比平台、广告主、媒体数据。
- CONFIRMED：差异处理完成，待关闭。
- CLOSED：金额冻结，不得修改；后续只能冲正。
- SETTLED：已完成收/付款或结转。

## 7. 对账

对账维度至少包括主体、账期、计费事件、投放/广告位和币种。差异分类：时间边界、去重口径、无效流量、归因差异、迟到事件、价格版本、接口漏传、人工调整。

差异单必须记录平台值、对方值、绝对差、差异率、证据、责任方、处理结论、调整流水和审批人。

## 8. 资金安全控制

- 充值、退款、人工调整、账单关闭和结算支付需要分权或复核。
- 禁止物理删除流水、账单、差异单和结算单。
- 余额快照与流水每日自动勾稽；不平立即阻止结算并告警。
- 所有导入对账文件留存原文件哈希、来源、解析版本和错误明细。

## 9. 财务验收

- 重复消息、并发扣费、消费者重启不会重复记账。
- 任意余额能由期初余额与流水重算得到。
- 账单关闭后再到达迟到事件会进入下一期或生成冲正，而不是覆盖历史。
- 报表消耗、计费事实、资金流水和账单差异均可解释。
- 使用含舍入边界、零值、负向冲正、大额和跨日的测试数据。
