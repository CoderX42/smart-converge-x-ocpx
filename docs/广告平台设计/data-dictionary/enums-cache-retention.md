# 枚举、缓存与保留

## 状态枚举原则

状态代码使用稳定英文大写；展示文本可本地化。未知状态必须安全降级，不可默认当作可投、可计费或已成功。

## 缓存 Key 模板

`scx:{env}:{domain}:v{schema}:{subject}:{resource}:{id}`

Key 必须登记所有者、值 schema、TTL、最大基数、失效方式和敏感级别。预算/幂等 Key 使用原子脚本和固定 Hash Tag（若集群需要），不可与普通缓存共用语义。

## 初始保留分类

| 分类 | 示例 | 初始策略 |
| --- | --- | --- |
| R1 临时 | nonce、限流、幂等热键 | 分钟到数日，按协议。 |
| R2 运营 | 接口日志、回传尝试 | 30-180 天，脱敏。 |
| R3 业务事实 | 触点、归因、计费事实 | 按账期/合规确认，通常多年。 |
| R4 财务审计 | 流水、账单、审计 | 法务/财务确认，禁止随业务删除。 |
| R5 素材归档 | 素材版本、审核证据 | 使用期 + 争议期。 |

具体期限仍是 M0 合规决策，不能把初始策略当作法律结论。
