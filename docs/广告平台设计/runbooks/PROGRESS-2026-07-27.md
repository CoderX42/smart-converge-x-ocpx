## 9. 硬规则（跨会话保留）

1. 一次只领取一个最小 Task；完成/暂停/阻塞时输出交付
2. 不 reset/clean/stash/rebase/覆盖/删除用户已有修改
3. 未经明确授权不连接生产/部署/真实凭据轮换
4. 数据库只前向迁移；不修改已执行 V*__*.sql
5. 不记录/输出/写入真实凭据值（仅指纹/长度/算法）
6. 菜单可见性不等于授权；后端权限码 + 对象 Scope 必须同时成立
7. HTTP 202 只表示可靠受理；继续核对 RawEvent/归因/Callback/Outbox/MQ/Redis/报表
8. 格式化只限定任务文件
9. 涉及公开协议/真实资金/生产/隐私/不可恢复操作时暂停请求授权
10. 多 Agent 模式下共享文件（POM/迁移序号/OpenAPI 根/menu/里程碑）由主 Agent 串行
