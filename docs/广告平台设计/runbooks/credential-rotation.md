# 凭据轮换 Runbook

## 触发条件

任何数据库、Redis、支付、对象存储、消息队列、API 签名或第三方平台凭据曾被提交到 Git、日志、工单或聊天记录时，立即按本 Runbook 处理。

## 步骤

1. 由环境所有者禁用或轮换受影响的真实凭据，并记录轮换时间与负责人；不要把新值写入仓库。
2. 将运行环境改为从密钥管理系统或部署环境变量读取新值。
3. 从当前分支删除明文值；若凭据已进入远程历史，由仓库管理员执行受控历史清理并强制所有开发者重新克隆。
4. 清除构建产物、日志、CI 输出和已部署前端包中的旧值。
5. 运行 secret scan，验证仓库、构建产物与文档不再命中旧值；将证据写入发布记录。
6. 复核最小权限、有效期、IP 白名单与审计告警，完成事故复盘。

## 本项目约定

- `.env`、`*.local` 仅限本机，已由 Git 忽略。
- 仓库只提交 `.env.example`，且只能包含本地模拟值和变量名。
- 浏览器端环境变量不是秘密；不得在 `VITE_*` 中放置服务端凭据或 HMAC 密钥。
