# M6 可观测性与故障演练手册

## 适用范围

本手册适用于 SCX MVP-A 的本地隔离环境和已获授权的发布环境。它覆盖回传任务、事务 Outbox、死信与 Prometheus 采集，不授权投放、回传重放、删除数据或访问真实媒体。

## 指标与告警

应用在 `/boot/actuator/prometheus` 输出以下低基数 Gauge；仅带 `state` 标签，不包含媒体、任务、事件或个人信息。

| 指标 | 状态 | 说明 |
|---|---|---|
| `scx_callback_queue` | `pending`、`retrying`、`paused`、`dead`、`delayed` | 持久化沙箱回传任务的当前队列深度 |
| `scx_outbox_queue` | `pending`、`retrying`、`dead`、`delayed` | 持久化事务 Outbox 的当前队列深度 |

告警平台应配置两个 5 分钟的 dead-letter 严重告警，以及两个 15 分钟、阈值 1000 的积压告警。阈值是 MVP 默认值；进入生产前必须根据实际吞吐、调度周期和 SLO 复核，并由外部监控平台配置接收人。项目不再内置 Prometheus/Compose 启动配置。

## 启用与验证

1. 使用包含本次指标代码的新 `scx-boot` 包启动隔离环境；不要用旧进程验证新端点。
2. 在外部 Prometheus/告警平台导入规则并指向应用的 metrics endpoint；本仓库不启动监控容器。
3. 检查应用采集端点返回指标文本，并在 Prometheus Targets 页面确认 `scx-boot` 为 `UP`。
4. 仅在隔离 sandbox 数据上制造一条可恢复的回传或 Outbox 失败，确认相应 Gauge 上升；恢复后确认 Gauge 回落。不得对真实媒体回调、生产队列或未知数据执行此操作。

<a id="outbox-or-dlq"></a>

## Outbox or DLQ

1. 先在运营页按媒体与任务范围查看 `DEAD`、`RETRYING` 和错误摘要，记录时间、任务、原因与操作者。
2. 检查 RocketMQ 可达性、主题存在性、应用日志和 Outbox 发布器开关；不得根据 HTTP 接收成功推断消息已投递。
3. 修复根因后，只对已授权的 sandbox 回传任务使用现有人工重放能力；保留审计记录。
4. 观察 `scx_callback_queue{state="dead"}` 或 `scx_outbox_queue{state="dead"}` 在下一采集周期下降，且相应 `SENT`/`SUCCEEDED` 事实已持久化。
5. 若死信持续增长，停止扩大演练范围，保留原始事实和日志，升级给发布负责人。

<a id="backlog"></a>

## Backlog

1. 当 `pending`、`retrying` 与 `delayed` 总和连续 15 分钟大于 1000 时，确认调度器仍运行、数据库连接正常、RocketMQ 和回调 mock 健康。
2. 核对最近 15 分钟积压变化和调度批次上限；先扩展消费者/调度资源或降低 sandbox 输入，再考虑重放。
3. 禁止通过删除 Outbox、回传任务或原始事件来清积压。恢复操作必须保留幂等和审计链路。

## 容量与故障演练

演练只允许在可丢弃的本地 Compose 环境进行，且每项单独执行并记录起止时间、输入量、队列峰值、恢复时间和数据对账结果。

| 演练 | 注入方式 | 通过条件 |
|---|---|---|
| Outbox 发布不可用 | 停止隔离 RocketMQ broker 或禁用发布器 | Outbox 转为 `RETRYING`/`DEAD`，无原始事件丢失，恢复后可投递 |
| 回传目标不可用 | 让本地 callback-mock 返回失败 | 回传按退避重试，最终进入 `DEAD`，授权重放可恢复 |
| 积压压力 | 向 sandbox 发送受控批量签名事件 | 积压、延迟与恢复时间可测；日报与原始事件对账一致 |

除已记录在 `MVP开发规划.md` 的隔离 Outbox 发布器不可用与恢复、以及 20 个签名事件/40 条 Outbox 小批量积压与恢复演练外，其余有状态演练尚未执行；小批量结果不构成生产容量承诺。每项完成后必须把实际输入、命令、数据库核验与结果补充到 `MVP开发规划.md`，不能以本手册替代运行证据。

对于不应影响其他本地进程的单条 Outbox 恢复演练，可在独立应用实例中通过
`--scx.tracking.outbox-scheduler-enabled=false` 暂停后台 Outbox 扫描。该开关默认开启，
仅暂停扫描，不会禁用受权限与媒体/任务范围校验约束的单条发布；演练结束后不得将其作为
生产常态配置。本轮已有一次本地隔离执行记录，实际证据以 `MVP开发规划.md` 的 M6 Outbox
演练条目为准。
