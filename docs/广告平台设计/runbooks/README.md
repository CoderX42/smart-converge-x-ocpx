# Runbooks

生产前必须把下列场景从通用步骤扩展为与实际部署命令、仪表盘、Owner 和权限一致的可执行 Runbook：

| 场景 | 当前基线 | 生产前证据 |
| --- | --- | --- |
| 事件接入错误/流量激增 | 15、16 | 限流/降级演练报告。 |
| 消息积压与死信 | 15 §6.1 | 扩容、隔离、重放演练。 |
| 回传失败 | 15 §6.2 | 429/5xx/密钥故障演练。 |
| 报表延迟或错数 | 09、15 | 水位、重算、重述验证。 |
| 账务不平/重复扣费 | 11、15 §6.3 | 阻止结算、勾稽、冲正演练。 |
| 配置错误发布 | 15 §6.4、17 | 灰度回滚和影响核验。 |
| 密钥泄露 | 14、15 §6.5 | 轮换/吊销和审计演练。 |
| 数据重放与修复 | 10、19 | dry-run、幂等和金额核验。 |
| 数据库/缓存故障 | 15、16 | 故障转移和恢复报告。 |
| 灾备切换 | 15 | RPO/RTO 恢复演练。 |

具体 Runbook 使用 [事故/操作模板](../templates/事故复盘模板.md) 并至少包含：触发、影响、权限、安全检查、诊断、缓解、恢复、数据/资金验证、回滚、升级和证据。
