# Smart Converge X 广告平台研发文档中心

本目录是 **Smart Converge X（SCX，瑶知智汇广告平台）** 从零研发、验收、上线及长期迭代的权威文档集。平台定位为单企业运营的效果广告与程序化交易平台，首版不建设对外售卖的 SaaS 多租户能力。

## 3. 文档权威级别

| 级别 | 含义 | 文件 |
| --- | --- | --- |
| L0 基线 | 未经明确决策不得违反。 | 00、06、已接受 ADR。 |
| L1 规范 | 实现和验收必须遵循。 | 01-17 专题文档。 |
| L2 执行 | 可持续更新的计划和证据。 | backlog、追踪矩阵、风险清单、交接记录。 |
| L3 模板 | 新文档/任务的统一格式。 | `templates/`。 |

- 文档基线版本：`0.2.0-draft`
- 当前产品阶段：M0 研发基线，尚未开始编码

任何实现不得把文档中的“规划能力”描述为“已实现”。功能状态以 Backlog、需求追踪矩阵和真实测试证据为准。
