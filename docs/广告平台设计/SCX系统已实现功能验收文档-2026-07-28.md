# SCX 系统已实现功能验收文档

> 历史状态声明：本文是 2026-07-28 已删除模块的验收快照，不代表当前 ADX/V70 代码。文中旧事件、归因、RTA、RocketMQ、环境变量配置与 `event-envelope.schema.json` 均已退出当前运行基线；当前事实见 [OCPX 双向转发引擎实现说明](OCPX双向转发引擎实现说明.md)。

> 验收日期：2026-07-28
> 系统：Smart Converge X（SCX，瑶知智汇广告平台）
> 当前阶段：MVP-A 沙箱闭环 / 完整 OCPX R1-00 本地收口
> 文档目的：说明当前已实现且有证据的功能、验收边界和未交付能力。

## 1. 验收结论

**结论：MVP-A 内部沙箱功能可验收；完整商业 OCPX 平台及生产媒体接入暂不通过。**

当前系统已经形成以下内部闭环：

```text
主数据与媒体范围
  → 追踪链接 / 监测任务
  → 点击、激活、注册、支付等事件接入
  → 幂等、设备去重、Last Click 归因
  → 回传任务 / Outbox / 重试 / 死信 / 人工重放
  → RTA 决策、日报、明细、维度报表和 CSV 导出
```

该闭环适用于开发、联调和隔离沙箱验收。以下事项尚未形成完整生产验收证据：真实第三方渠道签收、目标环境多角色回归、RocketMQ/Outbox 故障恢复、生产监控值班签收，以及独立多实例 20,000 QPS 稳态和 40,000 QPS 突发容量门禁。

## 4. 核心业务纵向切片验收

### 4.1 主数据到追踪任务

1. 管理员创建合作方、客户、产品和媒体渠道。
2. 为用户配置媒体对象范围。
3. 创建接入文档元数据、追踪链接和事件映射。
4. 创建监测任务并关联链接与渠道。
5. 启用任务后生成监测地址，页面可以按客户、产品、链接、任务和媒体查询。

**结果：通过（隔离本地环境）。** 读写接口同时进行权限、媒体范围和资源归属校验；页面可见性不被视为授权本身。

### 4.2 事件到归因

1. 调用方按契约生成 Canonical JSON 并使用 HMAC 签名。
2. 服务端校验渠道凭据、端点权限、时间戳、nonce、设备字段和任务。
3. 首次事件写入原始事实；重复相同载荷幂等返回；同一 ID 不同载荷返回冲突。
4. 设备窗口去重、转化业务键判重和 Last Click 规则生成归因结果。
5. 回执按渠道隔离返回；转化回执包含当前归因状态和原因码。

**结果：通过（本地单元、接口和隔离 E2E 证据）；真实媒体验收待完成。**

### 4.3 归因到回传

1. 命中有效归因后创建 Callback 和 Outbox 记录。
2. Worker 通过租约竞争领取任务，失败进入重试/延迟状态。
3. 超过重试上限进入死信；授权用户可单条暂停、恢复或人工重放。
4. 回传正文和幂等键保持稳定，重试不得产生重复业务回传。

**结果：通过（本地沙箱和队列运营证据）；生产 RocketMQ 恢复与第三方签收待完成。**

### 4.4 事件到报表与导出

1. 按冻结截止时间生成日报快照。
2. 通过日期、客户、产品、媒体、链接、任务和渠道组合筛选。
3. 查询事件明细、接入状态、去重状态、归因状态和脱敏设备哈希。
4. 创建受限异步 CSV 导出，完成后下载；失败任务可重试。

**结果：通过（本地报表、明细和导出 E2E 证据）。**

## 7. 明确未实现或未通过的能力

### 7.1 尚未实现的完整 OCPX 业务域

- 广告主/代理商/子代理商、广告账户、合同、授信和商务政策。
- 虚拟账户、双分录账本、充值、调账、退款、冻结、结算和发票。
- Campaign、AdGroup、Ad、预算、排期、投放状态、出价和审核。
- 媒体库存、版位、定向、频控、屏蔽策略和真实媒体对象同步。
- 素材中心、创意版本、DCO/AIGC 和媒体能力适配。
- 真实媒体账户授权、投放同步、成本回流和全域商业/财务对账。
- 以 CPA 50 CNY 为目标的自动出价、预算分配、模型实验和探索/利用。
- 反作弊、MTA、SKAdNetwork、Lookalike 等高级归因/风控能力。

### 7.2 当前不应宣称已交付的协议能力

- 正式 `FORM_SUBMIT` 事件及其 CPA 50 CNY 完整链路尚未实现；现有事件接入和转化回调不能替代该能力。
- 设备窗口去重不等于反作弊。
- RTA 决策接口不等于智能出价模型或完整 RTB/DSP。
- 监测任务不等于 Campaign/AdGroup/Ad 投放模型。

### 7.3 生产验收未通过项

- 目标环境备份、迁移、数据对账和可验证回滚仍需按 Runbook 签收。
- 生产管理员/运营/分析员/无范围账号的真实浏览器与 API 矩阵未完成。
- 历史真实凭据的双版本轮换、缓存失效和旧版本吊销未完成。
- RocketMQ 不可用/恢复、Outbox 积压恢复、Pending reclaim、DLQ 和全链路对账未完成。
- 真实第三方渠道尚未完成签名、权限、回执、回传和密钥轮换 UAT。
- 告警接收、值班签收、30 分钟观察、发布回滚和前向修复演练未完成。
- 独立多实例 20,000 QPS 稳态、40,000 QPS 突发及故障注入未通过。
