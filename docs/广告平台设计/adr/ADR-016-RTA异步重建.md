# ADR-016：RTA 异步重建

状态：Accepted（用户于本任务明确批准实施）。

媒体直接复用 OcpxMedia/mediaId，不新增渠道主体。删除旧 Profile、同步 RTA、微风/OPPO RTA 适配；点击与转化协议不属于删除范围。RTA 请求使用 202 受理，上游通过独立 HTTP 回调决定可投任务，再通知媒体。原设备业务值保留，允许协议字段映射。

Redis 承担 24 小时幂等、短期状态、恢复队列及原子终态计数。默认等待 5 秒；点击/曝光使用独立 rtaRequestId，放行默认 300 秒。Redis 不可恢复丢失不承诺零丢失。

XXL-JOB 复用 Boot 执行器：日志/统计每 5 秒批处理，日志清理每 10 分钟。成功阶段按 trace 稳定采样 10%，异常阶段全量，摘要保留 24 小时。长期仅新增小时统计，旧业务明细表隔离保留，不自动物理删除。

菜单重建为广告主接入、媒体接入、任务绑定、请求记录、流程日志、统计报表。接口路径不含版本号。首版以通用协议模拟上下游验收，不等于真实合作方或生产验收。
