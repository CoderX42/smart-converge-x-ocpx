# ADR-018：OPPO 媒体同步 RTA、点击和转化协议

状态：Accepted。2026-09-09 用户确认媒体即下游账户，按讨论方案实施。

在 ADR-017 的媒体统一异步约束上增加 OPPO 同步例外；原通用异步接口保持兼容。复用媒体配置、广告主接入、任务绑定。媒体保存协议及非秘密配置，签名密钥和 OPPO 上传凭据直写服务端配置。对外提供媒体 RTA 地址、数据库生成的 Integer 策略 ID、通过约定渠道交付的密钥，以及任务点击链接。

OPPO 多策略拆成微风单候选请求，使用现有有界派发器和 Redis 终态；截止后不恢复 ALLOW，不发媒体异步通知。策略使用全局唯一稳定自增整数，归属由任务的媒体校验。查询接口同步等待有界，超时不放行。

点击专属入口按策略恢复四实体路由，校验 RTA 决策和设备匹配；保留媒体请求与供应商请求的不同身份。默认点击 REQ 与 RTA request_id 相同，若合作方不同，必须显式传入 rta_request_id；不回退到仅设备匹配。正式联调必须确认关联规则。

OPPO 回传按媒体协议选择，使用点击归因 userIdType=1、AES 加密设备哈希(type=2)，不把设备哈希冒充智能分包。首期激活、注册、应用首次付费；不推断上游金额单位或生成付费流水。解析 HTTP 和 ret，复用现有转化事实与扣量流程，不增加账务行为。

请求协议文档 owner_id 有歧义：媒体配置显式选择 EMPTY 或 VALUE，默认 EMPTY；EMPTY 接收缺失/null，签名拼空字符串，VALUE 要求等于配置的十进制 ID。上线前双方确认。默认等待 1000ms，可配置 100–5000ms，正式预算由 OPPO 确认；异常默认不放行。

V133 为新增前向 SQL；不自动迁移任何环境。真实凭据、域名、OPPO owner_id/请求关联/时限确认和合作方验收不以源码测试替代。
