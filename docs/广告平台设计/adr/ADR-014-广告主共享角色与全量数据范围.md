# ADR-014：广告主共享角色与全量数据范围

- 状态：Accepted
- 日期：2026-08-14
- 部分取代：ADR-003 中“`ROLE_ADVERTISER` 固定只读”的结论

## 背景

V103 将所有广告主账号绑定到系统托管的共享 `ROLE_ADVERTISER`，并用 `shopId` 强制自身数据范围。当前业务要求由管理员统一配置广告主账号的 OCPX 动作权限，并可显式放开全部 OCPX 数据，而不能逐广告主产生不同角色或绕过服务端范围。

## 决策

1. 保留一个固定共享角色，由广告主管理页的专用接口维护；通用角色/用户管理仍隐藏并保护该角色。
2. 只有 `ROLE_ADMIN` 拥有 `ocpx:advertiser:role:manage`；该权限、系统权限和非 OCPX 权限永不进入可授予树。
3. `ocpx:advertiser:scope:all` 单独表达全量数据范围。没有它时继续使用 `shopId`；拥有它时只取消 OCPX 数据范围约束，不绕过动作权限。
4. 媒体、扣量规则和广告主新增/删除只有在全量范围开启时可授权，前后端双重校验。
5. 更新为全量替换并在事务中校验、补齐父级、替换角色菜单；成功后清理菜单缓存并注销全部广告主账号会话。
6. V107 一次性初始化为全部当前 OCPX 业务权限和全量范围；未来权限不自动追加。

## 结果

授权入口简单且所有广告主账号一致，动作权限与数据范围仍是两个独立门禁。V107 默认会显著扩大广告主账号能力，正式发布必须先备份和盘点账号；权限撤回通过同一页面完成，已执行迁移不得改写。
