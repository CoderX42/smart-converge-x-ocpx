# ADR-017：RTA 多上游协议与配置归属

状态：Accepted，2026-09-08 用户明确要求按此版本改造。

RTA 接入是一位广告主的一对多配置，入口归广告主管理；媒体通知配置归现有媒体，任务绑定归监测任务。RTA 独立目录仅保留请求记录、流程日志及统计报表。保留原权限码和角色关联，调整菜单归属，不新增媒体实体。

调整 ADR-016 中所有上游必须独立回调的限制：媒体继续统一 202 受理和异步通知，上游通过协议适配器支持同步 HTTP 决策或独立回调。初始适配器为 GENERIC_ASYNC 和 WEIFENG_RTA。协议能力、配置字段、批量限制与安全重试条件由代码定义；后台不能自行修改这些能力。

微风按 PDF v1.3 发送 id/device，解析 id/code；每次一个候选任务。aid/did 关联微风计划，校验其与点击链接一致，不使用 SCX 主键替代。未获供应商幂等承诺前不自动重发结果不明的请求。已验证的供应商 RTA ID 与事件自身 ID 分离，按微风 requestId 透传。

继续复用 Redis 状态机、XXL-JOB 异步日志和统计。密钥只在服务端配置文件中。V132 是前向扩展，不修改已执行迁移，不恢复旧 Profile。真实曝光外发因缺正式接口资料不在本次交付内；生产迁移、合作方 UAT 和放量另行验收。

实现依据及扩展约定见 [RFC](../RFC-RTA多上游协议扩展方案.md)，配置和验证见 [V132 交付说明](../RTA配置归属与多协议接入V132.md)。
