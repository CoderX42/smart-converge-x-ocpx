# ADR-0001 平台角色与分阶段边界

- 状态：Accepted
- 日期：2026-07-14
- 决策者：产品发起人（通过对话确认不做 SaaS）与文档设计基线

## 背景

SCX 长期目标包含广告主、媒体、归因、财务和交易能力，容易同时被理解为 DSP、SSP、Exchange 或纯归因平台，导致一期范围漂移。

## 决策

1. SCX 是单企业运营的综合广告平台，不作为多租户 SaaS 销售。
2. M0-M5 角色是“效果广告运营与归因结算平台”：管理内部需求与合作媒体，通过预配置投放和签名追踪形成展示、点击、转化、归因和结算闭环。
3. M6 才增加实时交易能力：接收媒体广告请求，对内部需求候选完成筛选、竞价和响应。
4. 外部 DSP 席位、开放 Exchange、PMP/程序化保量不是 M6 默认范围，需新 ADR。
5. “基础 OCPX”在 M3 表示转化采集、归因和回传闭环；自动出价、学习期和目标成本优化属于 M7。

## 影响

- 一期不需要 request/auction/win/loss 事实；展示/点击触点来自追踪链接或媒体协议。
- 事件、归因、账务契约需兼容 M6 新增请求和竞价标识。
- 产品文案不得在 M6 前宣称具备开放实时竞价交易所能力。

## 后续

首批媒体和广告主协议、广告格式、代理商支持范围仍需在 M0 关闭。
