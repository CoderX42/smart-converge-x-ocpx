# ADR-0002 技术栈与仓库结构

- 状态：Accepted（已落地）
- 日期：2026-07-14；工程基座落地：2026-07-15

## 背景

Vibe Coding 需要稳定、约束明确且易于自动验证的工程基线。本 ADR 已完成确认，并以 `boot-admin` 通用管理系统模板初始化 Smart Converge X 工程基座。

## 决策

- 单仓库管理前端、后端、契约、基础设施和文档。
- 管理面采用 **Java 17 + Spring Boot 3.x**；前端采用 **TypeScript + Vue 3**；事件网关在容量证明 Java 不足前沿用同一语言生态。
- OLTP 数据库采用 **MySQL 8.x**；Redis 作为缓存与原子计数。
- 事件总线采用 **Apache RocketMQ**。
- 分析库采用 **Apache Druid**。
- 对象存储采用 **阿里云 OSS**（S3 兼容协议）。
- OpenAPI、AsyncAPI/JSON Schema、数据库迁移和容器化本地环境纳入仓库。

## 落地基线

- 工程目录：`boot-backend`、`boot-fronted`。
- Java 根包：`com.yzytech.scx`；产品名称：`Smart Converge X`；中文名称：`智汇广告平台`。
- MySQL 数据库：`smart_converge_x`；后端默认端口：`9999`。
- 保留通用支付模块；支付密钥、证书和真实环境配置不写入仓库。
- 初始化数据库脚本、Docker Compose、本地环境配置、后台管理 Web 与后端构建入口已纳入工程；通用支付模块随后端保留。

广告业务首批媒体、协议、计费、数据合规和容量输入仍按 Q-001～Q-009 独立评审，不因工程基座落地而视为业务决策已完成。
