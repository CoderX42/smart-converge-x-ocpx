# ADR-0002 技术栈与仓库结构

- 状态：Proposed
- 日期：2026-07-14

## 背景

Vibe Coding 需要稳定、约束明确且易于自动验证的工程基线。当前尚无代码，技术选择必须在创建骨架前确认。

## 提议

- 单仓库管理前端、后端、契约、基础设施和文档。
- 管理面采用 Java + Spring Boot；前端采用 TypeScript + Vue 或 React（需最终选一）；事件网关在容量证明 Java 不足前沿用同一语言生态。
- PostgreSQL/MySQL 二选一作为 OLTP，Redis 作为缓存与原子计数，Kafka 作为事件总线，ClickHouse 作为分析库，S3 兼容对象存储保存素材和归档。
- OpenAPI、AsyncAPI/JSON Schema、数据库迁移和容器化本地环境纳入仓库。

## 待确认

具体语言/框架、版本、数据库二选一、前端框架、包管理器、部署目标和团队熟悉度。未确认前不得把本提议视为 Accepted。
