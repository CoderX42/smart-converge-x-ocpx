## 页面契约

| 页面 | 核心查询/表格 | 弹窗与行操作 |
|---|---|---|
| 广告主 | 编号、名称、余额、凭据引用、请求地址、宏、创建/修改时间 | 名称、请求地址、凭据引用、宏；编辑、充值 |
| 推广链接 | 编号、名称、广告主、平台、渠道号、投放/唤起链接、扩展信息、备注、时间 | 广告主、平台、名称、渠道号、两类链接、扩展、备注；编辑、删除 |
| 媒体 | 渠道 ID、名称、URI、凭据引用、宏、时间 | 名称、URI、凭据引用、宏；仅编辑 |
| 监测任务 | 编号、媒体、链接、广告主、业务编号、平台、单价、展示/点击链接、备注、时间 | 媒体、广告主、链接、名称、业务编号、单价、备注；编辑、删除 |
| 扣量规则 | 编号、链接、媒体、比例、时间 | 媒体、链接、比例；编辑、删除 |
| 时段报表 | 时间、四实体、扣量、展示、点击、CTR、消耗和全部转化列 | 四级联动、日期粒度、合计、CSV |
| 流程日志 | 时间、流程、事件、四实体、结果、HTTP、耗时、说明 | 日期、广告主到推广链接、媒体到监测任务、流程、阶段、结果、事件 ID 查询 |

七个列表页统一支持查询显隐、刷新、非持久化列选择、内部滚动、当前行高亮、默认 30 条和 `[10,30,60]` 分页。长文本支持 tooltip、点击复制和结果反馈。父级查询或表单值变化后清空不再有效的子级。

## V102 数据契约

- 广告主：只保留 `name/bid_url/credential_config_key/macro`。
- 推广链接：只保留关系、名称、数值平台、渠道号、`link_url/deeplink/link_ext/remark/is_delete`。
- 媒体：只保留 `name/uri/credential_config_key/macro`。
- 监测任务：只保留关系、`monitor_name/unit_price/biz_id/show_url/clk_url/remark/is_delete`。
- 扣量规则：只保留媒体、链接、比例和 `is_delete`；函数唯一索引约束生效路由。

V102 先输出并拒绝已软删广告主/媒体及 `WEB/OTHER` 或其他不可映射平台；通过预检后才把 `ANDROID/IOS` 转换为 `1/2`，再执行删列、改名、外键和 RBAC 调整。新平台范围为 1–4。V96–V101 不修改，SQL 不依赖迁移账本。

## 安全与发布门槛

浏览器只维护 `credentialConfigKey`，不返回或提交明文合作方凭据。V103 起新增广告主会一次性提交登录用户名和密码，并按当前产品决策取消管理面 URL 的 scheme/内网拦截；详见 V103 文档。通用媒体回调来自原 Feedback；KIMI 与小米 MI 专用实现已于 2026-08-17 移除。生产发布前必须盘点目标库全部广告主主键并分类为 `TEMPLATE_GET` 或 `AERIM`，通用模板凭据引用也必须在服务端完成解析验证；任一缺失即为 No-Go。

本基线不授权执行目标库迁移、填充生产注册表或凭据、宝塔部署、进程重启和真实第三方请求。
